# Family Travel Tracker

**A full-stack web application to plan, track, and reminisce about family travel adventures.**

---

## 🚀 Features
- **Trip Logging:** Add and organize travel details with ease.
- **Interactive Dashboard:** View and track your travel history.
- **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
- **Secure Data Storage:** Powered by PostgreSQL for reliable database management.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL (managed with pgAdmin)

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Family-Travel-Tracker.git
   cd Family-Travel-Tracker
   
2. Install all dependencies:

bash:
npm I

3. Set up the database:

Create a PostgreSQL database.
Update the database connection details in a .env file.

4. Start the application:

nodemon index.js

5. Open the app in your browser at http://localhost:3000.
